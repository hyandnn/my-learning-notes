# 公开学习笔记与发布规则

## 内容归属

- `docs/` 是已进入阅读网站的正文来源，不维护另一份手工复制的章节。
- `SLAM/` 保留尚未迁入网站的既有材料，后续逐主题迁移。
- 新草稿放在 `drafts/`，实验放在 `experiments/`。
- 私有知识库中的概念与项目笔记通过链接引用学习内容，不整章复制。

## 写作与审核

保留课程主线、推理、问答和反例。先交代目标、前置知识与符号，再给公式与解释；区分定义、假设、近似和经验结论。已有课程整理规则见 [LearningNoteRules](../SLAM/.regulation/LearningNoteRules.md)。

公开正文使用标准 Markdown 链接；问答使用 `<details>`；流程图使用 `mermaid` 代码块；公式使用 LaTeX。新增外部引用必须注明具体来源。

正文移动或改名时同步修复引用、目录和迁移记录，已公开路径必要时配置重定向。

## 导航与外观

使用主题名称而非只有周次的标题。章节编号保留在元数据或课程目录中。导航保持浅层，正文维持适合长文的宽度，首页使用少量课程卡片。空章节与未完成占位文件不进入网站目录。

## 发布

GitBook 同步 `main` 的 `docs/`。首次连接从 GitHub 导入 GitBook；日常以仓库为主编辑。若在 GitBook 编辑，先同步回 GitHub，再继续本地修改，避免两端同时改同一章节。

检查命令：`python3 scripts/check_docs.py`。链接检查通过后，还需预览公式、图表、问答折叠和移动端阅读。
