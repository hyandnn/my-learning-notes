# SLAM 学习路线

SLAM 将定位与建图放进同一个估计问题。为了理解它，这条学习路线先建立机器人系统的共同语言，再逐步引入不确定性与空间几何。

| 阶段 | 核心问题 | 当前状态 |
| --- | --- | --- |
| [Part I · 机器人基础](foundations/README.md) | 机器人怎样根据传感器、模型和历史信息认识世界？ | 9 篇章节与 1 篇总结可连续阅读 |
| [Part II · 概率状态估计](probabilistic/README.md) | 怎样表示与传播不确定性，并计算预测与校正？ | 15 篇章节与 1 篇总结已迁入网站 |
| [Part III · 空间状态估计](spatial/README.md) | 怎样描述位置、姿态、坐标变换与空间观测？ | Chapter 24–30 已迁入网站，后续章节待学习 |

这条路线采用“先解释为什么，再推导怎么算”的顺序。章节编号来自实际学习过程，与传统教材的目录不一一对应。

第一次阅读，从[机器人系统的信息流](foundations/robot-systems.md)开始；已有相关基础，可以先做[阶段自测](foundations/summary.md)。

后续材料与具体进度见[学习路线与进度](../roadmap.md)。
