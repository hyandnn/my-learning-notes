# 关于这份笔记

我是 Haoling Yang（Merci），学习背景是机器人系统工程，目前关注机器人感知、几何与状态估计。

这些笔记来自我的自学过程、课程讲解和问答整理，包含 AI 辅助讲解与编辑。它们保留有价值的推理过程，并随着进一步学习和核验持续修订。

## 内容范围

网站目前以机器人感知与 SLAM 的学习路径为主，兼顾概念、直觉、公式、例子与自测。工作项目的具体实现与内部资料在独立的私有知识库中维护。

## 来源与修订

引用教材、论文、文档或外部图示时，会在对应章节注明来源。当前直觉类章节主要是个人学习整理，不宣称来自某一指定教材。

发现影响结论的错误，会在正文注明修正并记录更新。无法确认的内容会标记为待核验；读者可以通过源仓库的 Issue 反馈具体页面与问题。

## 参与修订

欢迎通过源仓库的 Issue 提出勘误，或提交 Pull Request 补充例子与推导。反馈时请注明页面、具体段落和理由；涉及公式时，一并说明假设与符号。修改会经过文档检查与内容核验，再更新到阅读站点。
