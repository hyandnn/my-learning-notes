# 关于这份笔记

我是 Merci，机器人系统工程背景，目前在机器人行业做工程研发。这份网站记录我在工作之外的自学过程：从一个问题出发，整理概念、推导、例子，以及学习中产生的疑问。

## 为什么公开

短期内，这里首先是我的个人学习记录。把笔记公开，一方面给自己一点持续学习、及时整理的动力；另一方面，如果有人正在学习相同的内容，希望这些解释和例子也能帮上忙。

学习主要围绕公开的教材、论文、文档和开源项目展开，网站分享的是我对这些资料的理解与整理。引用会注明来源，公开资料的原文和图示仍遵循各自的使用许可。

## 内容范围与目标

内容围绕机器人技术展开。目前已覆盖机器人基础、概率状态估计、空间几何与建图／SLAM 系统，后续会随着实际学习，逐步扩展到运动学与动力学、规划与控制、仿真、机器学习和系统工程等方向。

我的长期目标是成长为一名具备全栈能力的机器人工程师：既能深入解决具体模块的问题，也能理解感知、决策、控制与硬件如何协同，把算法放进实际系统中验证。

这里的目录会跟着学习进度成长，尚未覆盖的方向也会逐步补充。

## 来源与整理方式

笔记来自公开资料、自学讨论和实践，也包含 AI 辅助讲解与编辑。我会保留有价值的推理、问答和反例，并随着进一步学习持续核验和修订。

引用教材、论文、文档或外部图示时，会在对应章节注明来源。发现影响结论的错误，会说明修正；尚不能确认的内容会标记为待核验。
